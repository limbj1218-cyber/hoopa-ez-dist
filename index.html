설치 안내 · 한 번만 설정하면 이후 업데이트는 자동입니다

현재 버전 5.1.0
이 방식의 장점
설치는 처음 한 번만 하시면 됩니다. 이후 프로그램이 개선되거나 오류가 수정되면 사용자가 아무것도 하지 않아도 자동으로 최신 버전이 적용됩니다.

Windows 설치

  1. 키보드에서 Windows 키를 누르고 powershell 이라고 입력하세요.
  2. Windows PowerShell 위에서 마우스 오른쪽 버튼을 누르고 “관리자 권한으로 실행”을 선택하세요.
    반드시 관리자 권한으로 실행해야 합니다. 그냥 실행하면 아래 명령이 실패합니다.
  3. 아래 명령을 복사해서 창에 붙여넣고 Enter를 누르세요.
    reg add "HKLM\Software\Policies\Google\Chrome\ExtensionInstallForcelist" /v "1" /t REG_SZ /d "mgcelohlecfhdjnlfekdbfkepckdjggc;https://limbj1218-cyber.github.io/hoopa-ez-dist/updates.xml" /f
    붙여넣기는 마우스 오른쪽 버튼 클릭 또는 Ctrl+V 입니다.
  4. 작업을 완료했습니다 라는 문구가 나오면 성공입니다.
  5. 크롬을 완전히 종료했다가 다시 켜주세요. (창을 모두 닫아야 합니다)
  6. 잠시 기다리면 확장 프로그램이 자동으로 설치됩니다. 주소창에 chrome://extensions 를 입력해서 목록에 후파의 이지워커 시즌2 가 보이면 완료입니다.
설치 직후 바로 안 보이면 크롬을 한 번 더 재시작해 보세요. 크롬이 정책을 읽고 설치하는 데 1~2분 걸릴 수 있습니다.

macOS 설치

맥에서는 설정 프로파일 파일이 필요합니다. 아래 파일을 내려받아 두 번 클릭한 뒤, 시스템 설정 › 일반 › 장치 관리(프로파일) 에서 설치를 완료해 주세요.

설정 프로파일 내려받기 (.mobileconfig)

설치 후 크롬을 재시작하면 Windows와 동일하게 자동 설치·자동 업데이트됩니다.

확인 방법

주소창에 chrome://policy 를 입력하면 ExtensionInstallForcelist 정책이 등록된 것을 볼 수 있습니다.

제거 방법 (클릭해서 펼치기)

정책으로 설치된 확장은 크롬 화면에서 직접 삭제할 수 없습니다. 제거하시려면 관리자 권한 PowerShell에서 아래 명령을 실행한 뒤 크롬을 재시작하세요.

reg delete "HKLM\Software\Policies\Google\Chrome\ExtensionInstallForcelist" /v "1" /f
