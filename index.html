후파의 이지워커 시즌2

설치 안내 · 한 번만 설정하면 이후 업데이트는 자동입니다

현재 버전 5.2.2
이 방식의 장점
설치는 처음 한 번만 하시면 됩니다. 이후 프로그램이 개선되거나 오류가 수정되면 사용자가 아무것도 하지 않아도 자동으로 최신 버전이 적용됩니다.

Windows 설치

  1. 키보드에서 Windows 키를 누르고 powershell 이라고 입력하세요.
  2. 검색 결과에 나온 Windows PowerShell 을 관리자 권한으로 실행합니다. 아래 두 가지 방법 중 편한 쪽을 쓰시면 됩니다.
    목록에서 마우스 오른쪽 버튼을 누르면 위와 같은 메뉴가 나옵니다.

    방법 A — 마우스 오른쪽 버튼

    Windows PowerShell 위에서 마우스 오른쪽 버튼을 누른 뒤 “관리자 권한으로 실행”을 선택합니다.

    방법 B — 오른쪽 패널

    검색 결과 오른쪽에 설명 패널이 함께 나오는 경우, 거기 있는 “관리자로 실행”을 눌러도 똑같습니다.

    반드시 관리자 권한으로 실행해야 합니다. 그냥 열기로 실행하면 아래 명령이 “액세스가 거부되었습니다” 오류로 실패합니다.
    실행하면 “이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?” 창이 뜹니다. 예를 눌러주세요. 창 제목에 관리자 라고 표시되면 제대로 실행된 것입니다.
  3. 아래 명령을 복사해서 창에 붙여넣고 Enter를 누르세요.
    reg add "HKLM\Software\Policies\Google\Chrome\ExtensionInstallAllowlist" /v "1" /t REG_SZ /d "mgcelohlecfhdjnlfekdbfkepckdjggc" /f
    복사가 안 되면? 명령문을 한 번 클릭하면 전체가 선택됩니다. 그 상태에서 Ctrl+C 를 누르세요.
    붙여넣기는 PowerShell 창 안에서 마우스 오른쪽 버튼을 누르면 됩니다. (Ctrl+V 도 대부분 됩니다)
  4. 작업을 완료했습니다 라는 문구가 나오면 성공입니다.
  5. 크롬을 완전히 종료했다가 다시 켜주세요. (창을 모두 닫아야 합니다)
  6. 아래 파일을 내려받아 압축을 풀어주세요.
    확장 프로그램 파일 내려받기 (.zip)
    압축을 풀면 hoopa-ez.crx 파일이 나옵니다.
  7. 크롬 주소창에 chrome://extensions 를 입력해서 확장 프로그램 페이지를 엽니다.
  8. 압축을 푼 hoopa-ez.crx 파일을 이 페이지 위로 끌어다 놓으세요 (드래그 앤 드롭).
    반드시 chrome://extensions 페이지 위에 놓아야 합니다. 다른 페이지에 놓으면 “패키지가 잘못되었습니다” 오류가 납니다.
  9. “확장 프로그램 추가” 를 눌러 설치를 완료합니다.
여기까지가 처음 한 번만 하시는 작업입니다. 이후 프로그램이 개선되거나 오류가 수정되면 사용자가 아무것도 하지 않아도 자동으로 최신 버전이 적용됩니다.
3번 명령을 건너뛰고 파일만 설치하면, 크롬이 보안상 확장 프로그램을 자동으로 꺼버립니다. 순서대로 진행해 주세요.

macOS 설치

맥에서는 설정 프로파일 파일이 필요합니다. 아래 파일을 내려받아 두 번 클릭한 뒤, 시스템 설정 › 일반 › 장치 관리(프로파일) 에서 설치를 완료해 주세요.

설정 프로파일 내려받기 (.mobileconfig)

프로파일 설치 후 크롬을 재시작한 다음, Windows 안내의 6~9번과 동일하게 확장 프로그램 파일(.zip)을 내려받아 chrome://extensions 페이지에 끌어다 놓으시면 됩니다. 이후 업데이트는 자동입니다.

크롬 계정이 여러 개인 경우

3번 명령은 한 번만 실행하시면 됩니다. 컴퓨터 전체에 적용되기 때문에 크롬 계정(프로필)이 몇 개든 다시 하실 필요가 없습니다.

다만 파일을 끌어다 놓는 설치(6~9번)는 사용하실 프로필마다 한 번씩 해주셔야 합니다. 회사용·개인용을 나눠 쓰시는 경우, 쓰실 프로필로 전환한 뒤 같은 방법으로 설치하시면 됩니다.

업데이트는 설치된 모든 프로필에서 각각 자동으로 이루어집니다.

삭제하려면

제거 방법 (클릭해서 펼치기)

chrome://extensions 에서 삭제 버튼으로 지우시면 됩니다.

설치 허용 설정까지 완전히 되돌리시려면, 관리자 권한 PowerShell에서 아래 명령을 실행한 뒤 크롬을 재시작하세요.

reg delete "HKLM\Software\Policies\Google\Chrome\ExtensionInstallAllowlist" /v "1" /f
